04 / efficiency

Less repeated work,
faster iteration.

EasyWAM provides efficiency controls across attention, memory, data loading and batched evaluation.

01 / COMPUTE

Efficient attention

Choose the fastest compatible FlashAttention 4, 3 or 2 backend, with PyTorch SDPA as a fallback. BF16 training reduces tensor bandwidth and memory use.

02 / MEMORY

Memory controls

LoRA, DeepSpeed ZeRO, gradient checkpointing and VAE micro-batching help fit larger workloads, with configurable speed and memory tradeoffs.

03 / DATA

Lean data pipeline

Sparse video decoding, indexed text caches, precomputed text embeddings and persistent DataLoader workers reduce repeated loading and processing.

04 / EVALUATION

Batched evaluation

Dynamic inference batching, multiple model workers per GPU, prompt caching and resumable evaluation improve GPU use and avoid repeated work.
