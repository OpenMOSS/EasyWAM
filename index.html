EasyWAM: A Unified and Efficient Framework for Training and Evaluating World Action Models

EasyWAM connects modular World Action Models, data processing, distributed training, parameter-efficient fine-tuning and scalable evaluation in one reproducible workflow.

01 / overview

One framework.
Every layer in sync.

From sparse video decoding to resumable evaluation, EasyWAM makes the entire WAM loop inspectable and repeatable.

01

Five architectures. One workflow.

Unified, MoT, MoT-Joint, MoT-IDM and Hidden share data, training, checkpoint and evaluation interfaces.

02

Three video backbones.

Wan2.2-TI2V-5B, Cosmos-Predict2.5-2B and FLUX.2 Klein-4B, with full-parameter training and LoRA fine-tuning.

03

Efficient from data to inference.

FlashAttention 2/3/4, sparse video decoding, text and prompt caches, DeepSpeed ZeRO, dynamic inference batches and resumable evaluation.

04

Five benchmark workflows.

LIBERO, LIBERO-Plus, RoboTwin, RoboDojo and RoboCasa365, with distributed evaluation and result summaries.

01 / ENVIRONMENT

Install EasyWAM

Full setup guide ↗

Run from the repository root after cloning. FlashAttention is optional and depends on your GPU.

TERMINAL / BASH
conda create -n easywam python=3.10 -y
conda activate easywam
pip install -U pip
pip install torch==2.7.1 torchvision==0.22.1 --extra-index-url https://download.pytorch.org/whl/cu128
pip install -e .
02 / TRAINING

Precompute and train

Training configuration ↗

After preparing LIBERO data and the backbone, precompute text embeddings and launch the example MoT run. Adjust the GPU process count for your machine.

TERMINAL / BASH
python scripts/precompute_text_embeds.py task=libero_easywam_mot_wan22
NPROC_PER_NODE=8 bash scripts/train_zero1.sh task=libero_easywam_mot_wan22
03 / EVALUATION

Choose a benchmark

Benchmark setup ↗

Set up the simulator and data with its guide, then replace the checkpoint placeholder with your own file.

TERMINAL / BASH
python experiments/libero/run_libero_manager.py \
  task=libero_easywam_mot_wan22 \
  ckpt=<path/to/checkpoint.pt>

04 / model zoo

Multiple models,
shared interfaces.

These architectures and backbones are supported by the framework. Check the Hugging Face collection for released checkpoints.

01 / SINGLE BACKBONE

EasyWAM-Unified

Jointly predicts future video and actions in a single Video DiT.

02 / DUAL BACKBONE

EasyWAM-MoT

Video DiT and Action DiT interact through mixed self-attention for action-only prediction.

03 / JOINT DENOISING

EasyWAM-MoT-Joint

Jointly denoises video and action tokens through mixed self-attention.

04 / CONDITIONAL VIDEO

EasyWAM-MoT-IDM

Uses teacher-forced conditional video for action prediction.

05 / HIDDEN FEATURES

EasyWAM-Hidden

Conditions a separate Action DiT on intermediate Video DiT features.
